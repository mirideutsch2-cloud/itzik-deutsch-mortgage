# איציק דייטש — ייעוץ משכנתאות (דף דוגמה)

דף דוגמה לאתר. כל התוכן (מספרים, המלצות, טלפון) לדוגמה בלבד וממתין לאישור.

- פונט: IBM Plex Sans Hebrew (Google Fonts, רישיון OFL)
- HTML/CSS/JS סטטי, בלי תלויות.

## קבצים
- `index.html` — דף הבית · `accessibility.html`, `privacy.html`, `terms.html`, `404.html` — עמודי חובה (טיוטות לאישור)
- `docs/BRIEF.md` — אפיון, מפת אתר, מערכת עיצוב ותסריט אנימציות
- `images/README.md` — אילו תמונות להעלות ובאיזה גודל
- עמודי המשנה נוצרים מ-`build_pages.py`
