# סרטון "שולחן" — איציק דייטש (טיוטה 1)

סרטון מושן אנכי 1080×1920, כ-23 שניות. סגנון: כהה (כחול-לילה + אדום), בהשראת רפרנס הלוגיסטיקה של מירי.

## תסריט (קריינות Jasper, ElevenLabs)
1. בבנק יש מישהו שדואג לבנק. ומי דואג לכם?
2. משכנתא לשלושים שנה, על סמך הצעה אחת? זה כמו לסובב רולטה ולקוות לטוב!
3. אני איציק דייטש, ואני יושב בצד שלכם של השולחן.
4. מנתח! מתמקח! ומלווה עד החתימה!
5. הבנק תמיד מרוויח. הפעם, גם אתם.
6. שלחו לי 'שולחן' בוואטסאפ, ואני חוזר אליכם עוד היום! — 053-638-0004

## קבצים
- `index.html` — המנוע: `window.renderFrame(t)` + `window.ready`. תמונה של איציק: `window.PHOTO = 'photo.jpg'` לפני הסקריפט.
- `render.js` — רינדור פריימים: `node render.js <dir> <fps> <dur> <scale> <worker> <workers>` (דורש שרת על פורט 8765 ותיקיית `fonts/`).
- `test.js` — פריימי בדיקה בזמנים נבחרים.
- `cover.html` / `cover-options.jpg` — 3 אפשרויות שער.

פונט: IBM Plex Sans Hebrew (OFL) — `fonts/fonts.css` נוצר מ-Google Fonts.
